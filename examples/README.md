# Horn design examples

Start with [the 800–1600 Hz modal example](800-1600-modal/README.md). It includes an already generated report, the winning acoustic STEP, driver-coupled response, horn impedance, shortlist and reproduction instructions. Open its `report.html` locally in a browser; GitHub displays the HTML source.

These are preserved experimental design outputs with their original source and evidence status. The current measured horn-loading comparison supports one separate exponential reference; real driver/interface qualification is still required before calling an example a validated physical assembly. Multiple-entry horns belong in [MEH Design Studio](https://github.com/timini/meh-design-studio).

For the measured exponential reference, see [the Post comparison](../docs/POST_HIXSON_VALIDATION.md). For the default uniform-piston workflow, see [the original worked example](../docs/WORKED_EXAMPLE.md).
