# Historical records

The files in this folder are dated records. They describe plans, research and results as they stood when they were written. They are kept for provenance and are not updated, so commands, defaults, file names and conclusions in them may be out of date. For the current state of the project start at [the documentation index](../index.md).

Archived run manifests under `examples/` and `data/validation/` record these files at their old `docs/` paths with their hashes at the time. That is expected: those manifests describe the source tree of an earlier run.
